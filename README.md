## 🚨 The Problem
Keeping track of your formative grades in IB is annoying. Between balancing tests, quizzes, etc, trying to figure out your actual class average takes way too long. 

## ✅ The Solution
This basic Java program aims to handle the math for you. Just plug in your formative marks, and it figures out where you stand based on the IB grade boundaries.

It is completely written in **100% Java** right now!

> [!NOTE]
> We are still beginners at this, so the app currently runs inside the terminal window.
> Plans might be made to revamp this in the future.

> [!WARNING]
> You will need to have **Java installed** on your computer in order to run the code.

---

## 🚀 Cool Things About the App
* **100% Java:** No messy setups or extra stuff to download, just Java code.
* **Saves Time:** Quickly tells you your formative standings without using a calculator.
